### Что нашёл
- **Симптом** — при запуске с `HOST=0.0.0.0`:
  - В шапке вместо ветки — «?» (ветка через `/api/status` показывает `branch: None`)

  Лог показывал: `HTTP Request: POST http://0.0.0.0:8799/mcp/git/ "HTTP/1.1 503 Service Unavailable"`

- **Причина** — `app/config.py:23-25`: URL для MCP формируются при импорте конфигурации через f-строку с подстановкой `HOST`. Когда `HOST=0.0.0.0`, клиент MCP пытается подключиться к адресу `0.0.0.0`, который предназначен только для прослушивания сервером и недоступен для клиентов.

### Что починил
- `app/config.py:23-25` — добавлена переменная `_mcp_host`, которая заменяет `0.0.0.0` на `127.0.0.1` для внутренних MCP-вызовов:
  ```python
  _mcp_host = "127.0.0.1" if HOST == "0.0.0.0" else HOST
  MCP_URL = f"http://{_mcp_host}:{PORT}/mcp/git/"
  ```
