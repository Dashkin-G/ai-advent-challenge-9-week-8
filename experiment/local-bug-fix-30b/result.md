### Что нашёл
- **Симптом** — запуск командой `.venv/Scripts/python.exe -m app.main` с `HOST=0.0.0.0` приводит к ошибке «Server returned an error response» при обращении к `/help`, а также к отображению «?» вместо ветки в шапке.
- **Причина** — `app/main.py:147`: в функции `project_context()` используется жёстко заданный хост `localhost` вместо значения из `config.HOST`, что приводит к попытке обращения к серверу по неправильному адресу при запуске с `HOST=0.0.0.0`.

### Что починил
- `app/main.py:147` — изменена строка, заменив `localhost` на `config.HOST` для корректной работы при разных значениях переменной окружения `HOST`.
