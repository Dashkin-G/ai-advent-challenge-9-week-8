# Smoke-сценарии

Пользовательские сценарии UI. Проходит их агент `qa` через Playwright MCP: приложение — `tests/serve.py` →
http://127.0.0.1:8765, Ollama запущен. Действие — по селектору, проверка — текст на экране или содержимое карточки, после
каждого шага — скриншот. Ответы модели меняются от запуска к запуску: проверяем, что шаг дошёл до результата и в нём есть
нужное, а не дословный текст.

## С1. /help: вопрос о проекте

Страница `/`. Разработчик спрашивает ассистента, как запустить проект.

1. Открыть http://127.0.0.1:8765/ и дождаться «ml-student-dropout» — заголовок «Ассистент разработчика»; в шапке проект
   `ml-student-dropout` и ветка — не «?»; в чипе модели «qwen3.5:4b · Ollama …», а не «Ollama не запущен».
2. Ввести в `#input` «/help как запустить проект?», нажать `#sendBtn`, дождаться «с всего» — в `#mcpCard` ветка и «Последний
   коммит»; в `#docsCard` три фрагмента документации с близостью; в `#answerCard` ответ по-русски со ссылкой на документацию в
   квадратных скобках.

## С2. Поддержка: ответ клиенту по обращению

Страница `/support`. Оператор готовит ответ на обращение T-1041: у клиента с API прогноз возвращает 422.

1. Открыть http://127.0.0.1:8765/support и дождаться «открытых обращений» — в шапке «CRM: 7 открытых обращений · MCP»; в очереди
   обращения с номерами T-…, последний пункт — «Вопрос о продукте».
2. Нажать `button.item[data-id="T-1041"]` — в `#ticket` номер T-1041, тема «Почему не работает прогноз? Ошибка 422», клиент
   «Игорь Ветров · Университет «Меридиан»».
3. Нажать `#sendBtn`, дождаться «с всего» — в `#crmCard` клиент «Игорь Ветров», технические данные обращения и «Вызовы MCP — 2»;
   в `#kbCard` «Искали ещё по ошибке из обращения» и фрагменты базы знаний; в `#answerCard` ответ начинается с обращения к
   Игорю.

## С3. Поддержка: вопрос о продукте без тикета

Страница `/support`. Оператор отвечает на общий вопрос — данные клиента не нужны, CRM не вызывается.

1. Открыть http://127.0.0.1:8765/support, дождаться «открытых обращений», нажать `button.item.free` — в `#ticket` «Вопрос о
   продукте» и кнопки-примеры вопросов.
2. Нажать `button.example:has-text("Насколько точен прогноз")`, дождаться «с всего» — в `#crmCard` «Без тикета — данные клиента
   не нужны»; в `#kbCard` фрагменты FAQ и документации; в `#answerCard` ответ по-русски без обращения по имени.

## С4. Файлы: задача → черновик → отмена

Страница `/files`. Ассистент создаёт файл в черновике, разработчик смотрит diff и отменяет — проект не меняется.

1. Открыть http://127.0.0.1:8765/files и дождаться «Выполнить» — поле задачи `#goal`, в `#changesCard` «Правки появятся здесь».
2. Ввести в `#goal` «Создай файл SMOKE.md с одной строкой: smoke-проверка», нажать `#runBtn`, дождаться «черновик · 1 файл» — в
   `#workCard` шаг с вызовом `write_file`; в `#changesCard` файл `SMOKE.md` со статусом «новый», строка «smoke-проверка» и кнопки
   «Применить» и «Отменить».
3. Нажать `#discardBtn` (не «Применить» — она пишет в ML-проект), дождаться «Черновик отменён» — в `#changesCard` «Черновик
   отменён — файлы проекта не менялись».

## С5. Поддержка: поиск по очереди

Страница `/support`. Оператор ищет конкретное обращение через поле фильтрации.

1. Открыть http://127.0.0.1:8765/support и дождаться «открытых обращений» — есть поле `#find` с плейсхолдером «Номер, тема или клиент».
2. Ввести в `#find` «T-1041», дождаться — в очереди осталась одна карточка T-1041 с темой про прогноз 422, остальные скрыты.
3. Ввести в `#find` «ветров», дождаться — в очереди остался тикет Игоря Ветрова (T-1041).
4. Очистить `#find`, дождаться — в очереди все 7 тикетов, последний «Вопрос о продукте».
